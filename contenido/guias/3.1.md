# 3.1 Lenguajes de desarrollo de software (10 reactivos)

## Elegir un lenguaje según el caso

| Necesidad | Lenguaje típico | Por qué |
|---|---|---|
| Embebidos o hardware con recursos mínimos | **C**, C++, Rust | Compilados, control de memoria, sin runtime pesado |
| Análisis de datos, prototipos, IA | **Python** | Tipado dinámico, bibliotecas (pandas, numpy) |
| Navegador / frontend | **JavaScript**, **TypeScript** | Se ejecutan en el cliente; TS agrega tipos estáticos |
| Backend web | PHP, Node.js, Java, C#, Python, Go | Según el ecosistema y el equipo |
| Empresarial multiplataforma | **Java**, C# | JVM/.NET, tipado estático, robustez |
| Android / iOS nativos | Kotlin / Swift | APIs nativas |
| Consultas a datos | SQL | Declarativo |

## Conceptos que se preguntan
- **Compilado vs. interpretado** (y JIT/bytecode: Java, C#)
- **Tipado estático vs. dinámico**; **fuerte vs. débil**
- **Datos primitivos** (int, float, char, boolean) vs. **estructurados** (arreglos, registros, listas, objetos)
- **Alcance (scope)**: local, global, de bloque, de clase; tiempo de vida
- **Accesibilidad** en Java: `private` (clase) < *package* (paquete) < `protected` (paquete + subclases) < `public`
- `static`: pertenece a la clase y se comparte entre las instancias
- Paso **por valor vs. por referencia**; mutabilidad (las listas de Python son mutables y se comparten por referencia)

> Ejemplo oficial: para datos numéricos y categóricos que deben «adaptarse dinámicamente a diversos tipos de datos», la respuesta es **Python** (tipado dinámico).
